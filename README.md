# SNOWY ❄️ — Modular GitHub Package v2.2

هذه الحزمة تجمع ملف التشغيل والواجهة القديمة بعد فصل الإعدادات والثيم وواجهة العناصر والإشعارات إلى وحدات Lua حقيقية.

## هيكل المستودع

```text
SNOWY/
├── SNOWY.lua                 # الملف الوحيد الذي تشغله من Delta
├── SNOWY_OLD.lua             # نسخة احتياطية من الملف الأصلي كما وصل
├── README.md
├── assets/
│   └── README.md             # مكان الأصول المستقبلية
└── src/
    ├── Main.lua              # يجمع الوحدات ويبني صفحات SNOWY
    ├── Settings.lua          # إعدادات المشروع
    ├── Theme.lua             # الألوان
    ├── UI.lua                # إنشاء الواجهة والعناصر والسحب
    └── Notifications.lua     # الإشعارات
```

## طريقة الرفع إلى GitHub من Android

1. فك ضغط `SNOWY_COMPLETE.zip`.
2. افتح مستودع https://github.com/irongg676/SNOWY .
3. ارفع **محتويات** مجلد `SNOWY_COMPLETE` إلى جذر المستودع، وليس المجلد الخارجي نفسه.
4. حافظ على أسماء الملفات والمجلدات والمسارات كما هي تماماً.
5. اجعل المستودع Public حتى يمكن تحميل الملفات من Raw.
6. افتح `SNOWY.lua` في Delta وشغّله.

## كيف يتم الربط؟

- `SNOWY.lua` يحمل `src/Main.lua` من GitHub.
- `src/Main.lua` يحمل `Settings.lua` و`Theme.lua` و`UI.lua` و`Notifications.lua` من مجلد `src`.
- جميع الوحدات تُستخدم فعلياً من Main؛ ليست ملفات فارغة أو أسماء شكلية.
- عند تحديث الملفات على GitHub، أعد تشغيل SNOWY لتحميل النسخ الجديدة. لا توجد مزامنة حية أثناء الجلسة.

## ما الذي يعمل وما الذي لم يُنفّذ؟

النسخة الأصلية احتوت واجهة SNOWY الداكنة، الألوان البنفسجية والزرقاء، السحب، التصغير، الإخفاء مع فقاعة إعادة الفتح، التبويبات، الإشعارات، معلومات السيرفر الحالي، وإعدادات الإشعارات وإعادة الموضع وإزالة الواجهة. تم الحفاظ على منطق الواجهة وتقسيم عناصرها المشتركة إلى وحدات.

Server Finder وServer Value Finder وAuto Carry وAuto Exit وPlayer ESP ما زالت عناصر واجهة فقط وليست وظائف منفذة. لا تُعرض على أنها تعمل. يمكن تطوير وظائف مماثلة داخل تجربة Roblox تملكها أو لديك تصريح لتطويرها.

## الاختبار

لم يتم تشغيل الحزمة داخل Delta أو التحقق من اتصال GitHub من داخل Roblox في هذه الجلسة. تحقق من أن الملفات رُفعت إلى المسارات الصحيحة وأن المستودع Public قبل التشغيل.
